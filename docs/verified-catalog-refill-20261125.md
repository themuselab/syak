## 검증과 중단 사유

검색어와 검색 지역을 그대로 분류에 사용하지 않는다. 해당 ID의 네이버 상세 원본 업종과 실제 주소로 분류·지역을 결정한다. 삭제 차단 ID, 기존 DB 중복, 미확인 업종·좌표, 폐업 표시를 배제한다. `is_partner`는 항상 false이며 기존 행은 덮어쓰지 않는다.

가격 범위 `60,000~70,000`을 `6000070000` 같은 정수로 합치지 않도록 검증한다. 단일 가격만 숫자로 저장하고 범위·문의 가격은 원문을 보존한다.

네이버에서 과도한 접근에 따른 서비스 이용 제한을 반환해 추가 조회를 중단했다. 브라우저 제어를 반환하고 확인 완료된 결과를 별도 파일로 확정했다. **756곳 전체 보충은 미완료이며 잔여 목표는 653곳**이다. 저장한 후보부터 이어서 검증해야 하며, 다른 IP나 우회 경로로 조회하지 않는다.

## 재현

후보·확정 원본·운영 반영 결과는 워크스페이스 로컬의 `.claude/local-backup/catalog-refill-20261125/`에 저장했다. 재개 시 최신 운영 DB와 삭제 차단 목록을 다시 대조해야 한다.
